# 历史记录（随项目走，可提交 Git）

| 文件 | 内容 |
|------|------|
| `download-history.json` | 已下载图片记录 |
| `prompt-history.json` | 已查询提示词记录 |

## 第一次使用（把浏览器里现有记录写入项目）

1. 打开扩展 **批量提示词** 页面  
2. 点击 **「绑定项目 data 目录」**，选择本项目文件夹下的 **`data`** 目录  
   （例如 `e:\tool\爆单MJ1.0.5\data`）  
3. 点击 **「立即同步全部记录到项目」**  
4. 用 Git 提交这两个 JSON 文件  

之后每次新增下载/查询记录，会自动（约 1.5 秒内）写入上述文件。

## 从 Git 恢复

重新加载扩展后，会自动把仓库里的 JSON **合并导入** 到浏览器 IndexedDB（只追加/更新，不删除）。

## 在电脑上查看

直接用记事本 / VS Code 打开本目录下的 `download-history.json` 即可查看全部下载记录。
